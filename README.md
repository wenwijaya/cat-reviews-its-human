# Cat Reviews Its Human

A [make.fun](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) program/v1 entry for **Make the AI Judge Laugh: Cat Reviews Its Human**.

## What it does

`main.ts` writes one funny one-star review, written by a house cat about its human, to `/output/entry.txt`. The review is a single line under 200 characters: a specific, recognisable complaint (an empty food bowl), in an unmistakably feline voice, with the sting saved for the last few words.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22+ (erasable-only TypeScript, no build step). The program creates `/output` if needed and exits 0 even if writing fails.
